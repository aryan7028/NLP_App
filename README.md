A small yet functional NLP-based web application built using Flask (Python backend) and HTML/CSS frontend, 
integrated with the Hugging Face API to perform real-world Natural Language Processing tasks.
This project demonstrates how NLP models can be deployed in a web environment to analyze user input text.

🚀 Features

The application provides the following functionalities:

😊 Sentiment Analysis
Detects whether the input text expresses positive, negative, or neutral sentiment.

🚫 Abuse Detection
Identifies toxic, abusive, or harmful language in text.

📩 Spam Message Analysis
Classifies whether a message is spam or legitimate.

All NLP operations are powered using Hugging Face pre-trained models via API.

Tech Stack

Backend: Python, Flask

Frontend: HTML, CSS

NLP: Hugging Face API

Version Control: Git, GitHub

Example Use Cases

Analyze user feedback sentiment

Detect abusive or toxic comments

Filter spam messages in chat systems
